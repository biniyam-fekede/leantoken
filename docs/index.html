Your AI writes too much code. Make it write less.

LeanToken is a free plugin for AI coding agents. Before your agent writes anything, it checks for a simpler way: code you already have, something built in, or no change at all. Then it measures what that actually saves.

    Add it in a minute
    
      
    Keep working the way you do now. Turn it off any time.
    
      
    
        
    
          
          
        
    
        
    
          
    
            
    Run these two commands inside Claude Code. It works automatically from then on.
    
            
    
              
    /plugin marketplace add biniyam-fekede/leantoken
    
              
    /plugin install leantoken@leantoken
    
            
    
            
    To turn it off /plugin disable leantoken
    
          
    
          
    
            
    For Cursor, Codex, or any agent that reads an instruction file. Run this in your project.
    
            
    
              
    npx github:biniyam-fekede/leantoken install --file AGENTS.md
    
            
    
            
    To remove it npx github:biniyam-fekede/leantoken uninstall --file AGENTS.md
