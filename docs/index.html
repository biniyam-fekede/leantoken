leantoken GitHub

Your AI writes too much code. Make it write less.

LeanToken is a free plugin for AI coding agents. Before your agent writes anything, it checks for a simpler way: code you already have, something built in, or no change at all.

    Add it in a minute
    
      
    
        
    
          
    Claude Code
    
          
    Run these two commands inside Claude Code. It works automatically from then on.
    
          
    /plugin marketplace add biniyam-fekede/leantoken
    
          
    /plugin install leantoken@leantoken
    
          
    Turn it off any time with /plugin disable leantoken
    
        
    
        
    
          
    Cursor, Codex, or any other agent
    
          
    Adds the checklist to the instruction file your agent already reads.
    
          
    npx github:biniyam-fekede/leantoken install --file AGENTS.md
    
          
    Remove it with npx github:biniyam-fekede/leantoken uninstall --file AGENTS.md
