Make your coding agent write less, and prove it.

LeanToken is a small, open-source layer for AI coding agents. Before writing code, it has the agent check for the simplest complete solution. It also ships a benchmark that measures whether that actually saves code, tokens and money without breaking anything.

See it trim code ↓ View on GitHub

What it does

AI agents often over-build. They install a library to format one date, or write a parser when the project already has one. LeanToken fixes the decision, not the code.

01 · Guide

A 7-step checklist

Before coding, the agent checks: is this needed? Does the codebase, the language, or the platform already solve it? Only then does it write the smallest complete change.

02 · Explain

A decision record

The agent ends each task with the step it stopped at, like rung=3 used a built-in, so you can see why it chose a solution.

03 · Measure

A paired benchmark

The same tasks run with and without LeanToken. It compares lines, tokens, cost, time, and new dependencies, and runs hidden tests to make sure nothing broke.

    Install in under a minute
    
    
    Keep using your agent exactly as before. LeanToken works in the background.
    
    
    
      
    
        
    Claude Code plugin
    
        
    Loads the checklist automatically at the start of every session.
    
        
    /plugin marketplace add biniyam-fekede/leantoken
    
        
    /plugin install leantoken@leantoken
    
        
    Turn it off any time: /plugin disable leantoken
    
      
    
      
    
        
    Any agent (Cursor, Codex, …)
    
        
    Adds the checklist to the instruction file your agent reads. Remove it with one command.
    
        
    git clone https://github.com/biniyam-fekede/leantoken
cd leantoken && npm install && npm link
    
        
    leantoken install --file AGENTS.md
    
      
    
    
    
  
    

    


    
  
    
    
    How it's measured
    
    
    Fewer lines don't automatically mean better code, so correctness comes first.
    
    
      
      
    1. Each task starts from the same small repo, in a fresh throwaway copy.
      2. 
      
    2. The agent solves it twice: once normally, and once with the LeanToken checklist. Same model, same prompt.
      3. 
      
    3. Hidden tests are added only after the agent finishes, so they can't be read or gamed.
      4. 
      
    4. Lines changed, tokens, cost, time, and new dependencies are recorded, and the report shows medians across repeated runs.
      5. 
    
    
    
    leantoken bench --runs 3 --model sonnet
